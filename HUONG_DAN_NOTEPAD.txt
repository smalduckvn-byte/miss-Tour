          HƯỚNG DẪN MỞ VÀ CHẠY WEBSITE BẰNG NOTEPAD
================================================================================

Chào bạn, tôi đã chuẩn bị sẵn cho bạn 2 tệp đặc biệt để phục vụ theo đúng yêu cầu:

1. [CHAY-WEBSITE.bat] : File kịch bản chạy tự động (viết bằng Notepad).
   - Bạn chỉ cần NHẤP ĐÚP CHUỘT vào file này là trang web sẽ tự động mở ngay trên trình duyệt (Chrome, Edge, Cốc Cốc...).
   - Ngoài ra có menu để bạn chọn mở bằng Notepad hoặc mở thư mục.

2. [website-all-in-one.html] : File HTML gộp toàn bộ mã nguồn vào DUY NHẤT 1 file.
   - Chứa đầy đủ: Toàn bộ cấu trúc HTML trang chủ + Toàn bộ giao diện CSS + Toàn bộ hiệu ứng JavaScript.
   - Thích hợp nhất để bạn mở bằng ứng dụng Notepad hoặc Notepad++, xem toàn bộ code trong 1 nơi và nhấp đúp để chạy.

--------------------------------------------------------------------------------
HƯỚNG DẪN 3 CÁCH SỬ DỤNG
--------------------------------------------------------------------------------

CÁCH 1: CHẠY TRANG WEB NHANH NHẤT (Khuyên dùng)
- Nhấp đúp chuột vào file: CHAY-WEBSITE.bat
- Trình duyệt sẽ tự động bật lên và hiển thị toàn bộ giao diện website du lịch tuyệt đẹp.

CÁCH 2: CHẠY TRỰC TIẾP FILE ALL-IN-ONE
- Nhấp đúp chuột vào file: website-all-in-one.html
- Trang web sẽ chạy độc lập, đầy đủ hình ảnh, slider, form đặt tour và hiệu ứng.

CÁCH 3: CÁCH MỞ VÀ CHỈNH SỬA CODE BẰNG NOTEPAD
- Bước 1: Nhấp chuột phải (Right-click) vào file "website-all-in-one.html" (hoặc "index.html").
- Bước 2: Chọn "Open with" (Mở bằng) -> Chọn "Notepad" (hoặc "Notepad++").
- Bước 3: Bạn có thể tự do chỉnh sửa nội dung văn bản, tiêu đề, số điện thoại hotline, thông tin tour...
- Bước 4: Nhấn Ctrl + S để lưu lại.
- Bước 5: Quay lại trình duyệt và bấm phím F5 để xem thay đổi ngay lập tức!

--------------------------------------------------------------------------------
LƯU Ý KHI TỰ TẠO FILE CODE MỚI BẰNG NOTEPAD:
- Khi mở ứng dụng Notepad trắng và dán code vào:
  + Chọn Menu File -> Save As... (hoặc ấn Ctrl + Shift + S).
  + Tại dòng "Save as type", đổi từ "Text Documents (*.txt)" thành "All Files (*.*)".
  + Tại dòng "File name", gõ tên file có đuôi .html (ví dụ: my-web.html) hoặc .bat (ví dụ: chay.bat).
  + Tại dòng "Encoding", chọn "UTF-8" để không bị lỗi font chữ tiếng Việt có dấu.
  + Bấm nút "Save" để hoàn tất.
